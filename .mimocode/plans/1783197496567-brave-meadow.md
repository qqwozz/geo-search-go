## API Client (`src/api.js`)

```js
const BASE = '/api'

export async function search(query, lat, lon, { radius = 2000, limit = 20, sort = 'relevance' } = {}) {
  const params = new URLSearchParams({ q: query, lat, lon, radius, limit, sort })
  const res = await fetch(`${BASE}/search?${params}`)
  if (!res.ok) throw new Error((await res.json()).error || 'Search failed')
  return res.json()
}

export async function autocomplete(query) {
  const params = query ? `?q=${encodeURIComponent(query)}` : ''
  const res = await fetch(`${BASE}/autocomplete${params}`)
  return res.json()
}

export async function health() {
  const res = await fetch(`${BASE}/health`)
  return res.json()
}
```

## Component Design

### Header.jsx
- App title "Geo Search"
- Small health dot (green/red) polled every 30s via `GET /api/health`

### SearchBar.jsx
- Text input with debounced autocomplete (300ms)
- Dropdown shows `suggestions[]` from `/api/autocomplete`
- On Enter or suggestion click: calls `onSearch(query)`
- Shows loading spinner during search

### QuickFilters.jsx
- Row of chip buttons: Кофе, Завтрак, Работа, Терраса, Ужин
- Each chip prepends/appends to query and triggers search
- Active chip highlighted

### ResultsList.jsx
- Vertical scrollable list of `POICard` components
- Shows total count and "cached" badge if applicable
- Empty state when no results

### POICard.jsx
- Name, category badge, rating stars, review count
- Distance (meters/km)
- Feature tags (wifi, terrace, quiet, etc.) as small pills
- Explanation text (italic)
- Favorite toggle button (heart icon)
- Click → opens DetailModal

### MapView.jsx
- Full-height Leaflet map using `react-leaflet`
- Blue markers for each POI from results
- Marker click → selects POI (opens modal or highlights card)
- User location marker (blue dot)
- Cluster markers if dense (optional — skip for simplicity, use CircleMarker)

### DetailModal.jsx
- Overlay/modal when a POI is selected
- Full info: name, address, phone, website, hours, rating, all features
- "Построить маршрут" link → `https://yandex.ru/maps/?rtext=...` (from user location to POI)
- "Поделиться" button → copies shareable URL with query params
- Close button

## Dockerfile Update

```dockerfile
FROM node:20-alpine AS build
WORKDIR /app
COPY package.json package-lock.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=build /app/dist /usr/share/nginx/html/
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
```
